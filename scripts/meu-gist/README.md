Melhorias para cadastro de cartas de Yu-Gi-Oh e Pokémon no site mypcards.com
* Remoção de barra principal, breadcrumbs e itens que poluem o layout.
* Posicionamento do foco sempre na pesquisa.
* Auto-completar caracteres na barra de pesquisa para facilitar a procura por código de carta.
* Ocultação de Linguagens e Raridades não utilizadas frequentemente.
* Setar o printing como 1st Edition no caso de Yu-Gi-Oh.
* Adicionar colapsibilidade aos itens dos carrinhos para visualizar facilmente os itens dos carrinhos inferiores.
* Contagem de cards existentes na coleção para evitar compras duplicadas
* Demonstrar itens duplicados no(s) carrinho(s)

Eu utilizo o script no AdGuard e Tampermonkey
